# CrossScreenBridge · 跨屏桥

跨屏桥是一款面向 Windows 双电脑环境的局域网文件传输工具。按下 `Ctrl+Alt+M`，在本机资源管理器中选择文件或文件夹，再把鼠标移入另一台电脑的屏幕，即可在远端资源管理器中选择保存目录并确认传输。

当前稳定版本：`v6.8-final`

## 主要功能

- 自动发现同一局域网中的另一台设备，也支持输入 IPv4 地址手动连接
- 鼠标可从屏幕左侧或右侧边缘进入另一台电脑
- 支持远端移动、单击、双击、任务栏悬停和窗口按钮等完整鼠标交互
- 自动识别远端资源管理器当前打开的目录
- 支持单文件、多文件和整个文件夹传输
- 保留文件夹层级和空文件夹
- 传输前显示最终目标路径，由用户确认后才开始发送
- 接收端写入磁盘并返回确认后，发送端才显示成功
- 同名文件和文件夹自动重命名，避免覆盖已有内容
- 后台系统托盘运行，不显示任务栏按钮或 PowerShell 窗口
- 单实例运行，重复启动时会提示软件已经在运行
- 支持开机自启动、鼠标刷新率、灵敏度、触发边缘、通知和默认保存位置设置

## 系统要求

- Windows 10 或 Windows 11
- Windows PowerShell 5.1 和系统自带的 .NET Desktop 组件
- 两台电脑处于能够互相访问的同一局域网
- Windows 网络配置建议设为“专用网络”

笔记本使用 WLAN、台式机使用有线网络没有问题，只要路由器允许无线和有线设备互访，并且未开启 AP 隔离、访客网络隔离或类似限制。

## 安装与首次运行

1. 下载发布包并完整解压，不要只单独复制启动脚本。
2. 将同一版本的程序放到两台 Windows 电脑上。
3. 两台电脑分别右键运行一次 `Setup-Firewall.cmd`，在管理员授权窗口中选择“是”。
4. 双击 `Start-CrossScreenBridge.vbs` 启动软件。
5. 首次运行时选择默认接收目录。
6. 两台设备启动后，等待托盘提示发现对方。

推荐始终使用 `Start-CrossScreenBridge.vbs` 启动。它会从进程创建阶段隐藏 PowerShell 控制台。`Start-CrossScreenBridge.cmd` 是兼容入口，启动后会立即退出自身窗口。

## 使用流程

1. 确保两台电脑都已运行跨屏桥，并且设备列表中显示对方。
2. 在发送方按下 `Ctrl+Alt+M`，进入等待选择状态。
3. 在 Windows 资源管理器中单选、多选或框选需要发送的文件和文件夹。
4. 将鼠标移向已启用的屏幕边缘，越过边缘后鼠标会进入接收方屏幕。
5. 在接收方操作资源管理器，进入希望保存文件的目录。
6. 按 `Enter`，接收方会显示识别到的完整目标路径。
7. 再按一次 `Enter`，或用鼠标点击“是”，确认传输。
8. 确认后鼠标立即返回发送方，文件在后台传输且只发送一次。

按 `Esc` 或再次按 `Ctrl+Alt+M` 可以随时取消当前跨屏操作并召回鼠标。软件接管跨屏后会终止本机原生 OLE 拖放，避免选中的文件被 Windows 意外移动到桌面或其他资源管理器窗口。

## 目标目录识别

- 鼠标位于资源管理器窗口时：使用该窗口当前打开的文件夹
- 鼠标位于桌面时：使用当前用户的桌面目录
- 鼠标位于其他窗口时：使用设置中的默认接收目录

确认窗口会显示最终路径。当前版本识别的是资源管理器“当前打开的目录”，不会把鼠标悬停但尚未打开的子文件夹图标作为目标。

## 系统托盘

跨屏桥默认在后台运行，不显示任务栏按钮。关闭或最小化主窗口只会将它隐藏到系统托盘；双击托盘图标可以重新打开。

托盘右键菜单提供：

- 打开主窗口
- 取消当前跨屏操作
- 打开设置
- 重启跨屏桥
- 退出程序

选择“重启跨屏桥”后，程序会先释放全局快捷键、网络端口和单实例锁，再通过隐藏启动入口重新运行。为防止误触，重启前会要求确认；当前跨屏操作和正在进行的传输会被中止。

收到文件、弹出路径确认或完成传输时，主窗口不会自动出现。需要查看主界面时请主动双击托盘图标。

## 设置

在托盘图标的右键菜单中选择“设置…”可以调整：

- 当前用户登录 Windows 时自动启动
- 远端鼠标刷新率：60、120、144 或 240 Hz
- 远端鼠标灵敏度：50%–200%
- 跨屏触发边缘：两侧、仅左侧或仅右侧
- 是否显示发送和接收完成通知
- 默认接收目录

配置保存在 `%APPDATA%\CrossScreenBridge`。开机启动使用当前用户注册表的 `Run` 项，不需要管理员权限。如果启用开机启动后移动了软件目录，请在设置中关闭再重新开启一次，以刷新启动路径。

## 网络端口

| 协议 | 端口 | 用途 |
| --- | ---: | --- |
| UDP | 45990 | 局域网设备发现 |
| TCP | 45991 | 文件与目录数据传输 |
| UDP | 45992 | 跨屏鼠标和控制消息 |

`Setup-Firewall.cmd` 会为这些端口创建专用网络入站规则。

## 文件传输规则

- 单个文件上限为 100 GB
- 文件夹会保留根目录、全部子目录和空文件夹
- 目标位置存在同名内容时自动生成新名称，不覆盖原文件
- 只有接收端完成磁盘写入并返回确认后，发送端才显示成功
- 网络中断、协议版本不一致或目标无法写入时会明确显示失败
- 发送过程中请确保源文件仍然存在并可读取

## 故障排查

### 搜索不到另一台设备

1. 确认两边运行的是同一版本。
2. 确认两台电脑处于同一主人网络，而不是访客网络。
3. 将 Windows 网络配置为“专用网络”。
4. 两边重新以管理员身份运行 `Setup-Firewall.cmd`。
5. 检查路由器是否开启 AP 隔离、无线客户端隔离或有线/无线隔离。
6. 在主窗口中输入另一台电脑的 IPv4 地址手动连接。

可以在 PowerShell 中测试文件传输端口：

```powershell
Test-NetConnection 对方IPv4地址 -Port 45991
```

正常结果应显示 `TcpTestSucceeded : True`。即使禁用了 ICMP 或系统不响应 `ping`，只要这个 TCP 测试成功，仍然可能正常连接和传输。

### 快捷键没有反应

- 确认使用的是 `Ctrl+Alt+M`，不是旧版本的 `Alt+C`
- 检查是否有其他软件占用了相同全局快捷键
- 从托盘菜单退出全部旧实例后重新启动

### 找不到程序窗口

程序默认隐藏在系统托盘。请展开任务栏右下角的隐藏图标区域，并双击跨屏桥图标。

### 开机后没有启动

如果软件目录曾被移动，请手动启动程序，在设置中关闭“开机自启动”，保存后再重新开启。

## 安全说明

跨屏桥面向可信的家庭或办公局域网。当前版本没有互联网级身份认证和端到端加密，请不要将相关端口映射到公网，也不要在不可信的公共网络中运行。

## 源码文件

- `CrossScreenBridge.cs`：主程序、界面、网络传输和跨屏控制实现
- `CrossScreenBridge.ps1`：编译并启动内嵌 C# 程序
- `Assets/CrossScreenBridge.ico`：Windows 窗口和系统托盘多尺寸图标
- `Assets/CrossScreenBridge-Tray.png`：透明背景图标母版
- `Start-CrossScreenBridge.vbs`：无控制台窗口启动入口
- `Start-CrossScreenBridge.cmd`：兼容启动入口
- `Setup-Firewall.cmd`：Windows 防火墙规则配置
