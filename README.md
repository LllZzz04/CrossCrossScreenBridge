# 跨屏桥（Windows MVP）

## 使用方法

1. 把整个 `CrossScreenBridge` 文件夹复制到笔记本和台式机。
2. 两台电脑连接同一个局域网。
3. 两边分别双击 `Start-CrossScreenBridge.cmd`。
4. 首次启动时，允许 Windows 防火墙中的“专用网络”访问。
5. 首次启动会提示选择接收文件的保存位置；之后可用窗口右上角的“更改保存位置”调整。
6. 设备出现后选中对方，按 `Alt+C`，把文件或文件夹拖进下方发送区域。
7. 文件夹传输会保留根文件夹、全部子目录以及空文件夹。

如果自动发现没有显示设备，可在“手动连接”输入框中填写另一台电脑的 IPv4 地址。程序会先测试 TCP 45991，连接成功后设备会立即进入列表。

## 网络端口

- UDP 45990：局域网设备发现
- TCP 45991：文件传输

如果设备互相看不到，请确认两台电脑处于“专用网络”，并允许 PowerShell 通过防火墙。

## 当前版本说明

这是无需安装开发环境的 MVP。它已经支持逐网卡自动发现、手动 IP 连接、全局快捷键、拖放、完整文件夹结构、可配置接收目录、传输进度和自动重命名冲突文件。

单个文件上限为 100 GB。发送端必须收到接收端“已保存”的确认后才会显示发送成功；连接中断或协议版本不一致会明确显示失败。

真正把 Windows Explorer 的拖拽光标无缝接管到另一台物理电脑，需要实现 Windows Shell/OLE 拖放代理和跨设备鼠标边缘捕获；这部分适合在验证传输稳定后加入原生安装版。
