# 跨屏桥（Windows MVP）

## 使用方法

1. 把整个 `CrossScreenBridge` 文件夹复制到笔记本和台式机。
2. 两台电脑连接同一个局域网。
3. 两边分别双击 `Start-CrossScreenBridge.cmd`。
4. 两边各运行一次 `Setup-Firewall.cmd`，在管理员确认窗口中选择“是”。
5. 首次启动会提示选择接收文件的保存位置；之后可用窗口右上角的“更改保存位置”调整。
6. 设备出现后选中对方，按 `Ctrl+Alt+M` 进入等待选择状态，再选择文件并移动到屏幕边缘。
7. 文件夹传输会保留根文件夹、全部子目录以及空文件夹。

## 跨屏鼠标传输（实验版）

1. 按 `Ctrl+Alt+M` 进入“等待选择”状态。
2. 在 Windows 资源管理器中点击、框选或多选需要传输的文件和文件夹。
3. 选好后将鼠标推过主屏幕左边缘或右边缘；软件此时读取选择并开始控制另一台设备。如果按住文件拖到边缘，软件会取消 Windows 本地拖放后再接管。

选择完成并松开鼠标后，软件会在独立线程预先缓存资源管理器选择。跨越屏幕边缘时不再同步等待资源管理器退出原生拖放，因此切屏延迟会明显降低。

进入远端时会传递越界方向和纵向比例：从发送方右边缘离开，就从接收方左边缘对应高度出现；从左边缘离开则从接收方右边缘出现。持续朝越界方向移动不会再让远端光标卡在错误边缘。

Raw Input 位移会先用原子计数器合并，再由启用 Windows 1 ms 高精度计时的独立定时器以约 240 Hz 发送；控制消息复用一个 UDP socket。它能匹配高刷新率屏幕的观感，同时不会恢复逐条网络发送或积压旧方向消息。

接收方使用虚拟桌面绝对坐标注入并设置 `MOUSEEVENTF_MOVE_NOCOALESCE`：Raw Input 位移先换算成精确目标坐标，再进入 Windows 输入管线。这样既保留任务栏悬停、Shell 预览和提示框等完整交互，也避免接收方再次应用指针加速度造成灵敏度升高。
4. 跨屏后的左键会发送给接收方，可单击、双击资源管理器窗口并进入需要的目标目录。
5. 选好目录后，在发送方键盘按 `Enter`，接收方显示目标路径确认框。
6. 再按一次 `Enter` 可确认“是”；也可以用远端鼠标点击“是”或“否”。确认后鼠标立即返回原电脑，文件只传输一次。
7. 按 `Esc` 或再次按 `Ctrl+Alt+M` 可取消并把鼠标召回本机。

## 系统托盘

跨屏桥不会显示在 Windows 任务栏。关闭或最小化主窗口只会隐藏到系统托盘；双击托盘图标可重新打开。右键菜单提供打开、取消当前跨屏、更改接收位置和彻底退出。

推荐直接双击 `Start-CrossScreenBridge.vbs`。它使用 Windows Script Host 以窗口模式 `0` 创建 PowerShell，从进程创建时就没有控制台窗口。`Start-CrossScreenBridge.cmd` 现在也只调用该 VBS 并立即退出。应用启动后默认只显示托盘图标；接收文件和显示传输确认框都不会打开跨屏桥主窗口。

程序使用当前 Windows 登录会话范围内的命名互斥锁，只允许一个实例运行。重复启动时会提示“跨屏桥已经在运行”，随后第二个进程立即退出，不会重复注册快捷键或占用网络端口。

## 设置

从托盘右键菜单选择“设置…”可以调整：

- 当前用户登录 Windows 时自动启动（无需管理员权限）
- 远端鼠标刷新率：60、120、144 或 240 Hz
- 远端鼠标灵敏度：50%–200%
- 允许触发跨屏的边缘：两侧、仅左侧或仅右侧
- 是否显示发送及接收完成的托盘通知
- 默认接收目录

设置保存在 `%APPDATA%\CrossScreenBridge`。开机启动项保存在当前用户注册表的 `Run` 项中。

鼠标进入接收方后，发送方使用 Windows Raw Input 读取原始位移，并把本机光标锁定、隐藏；不再通过反复重定位光标计算移动量。低级鼠标钩子会拦截这次操作的本机拖放事件，防止资源管理器把原文件移动到桌面或边缘窗口。

接收方会识别松开位置所在的资源管理器窗口，并将该窗口当前打开的文件夹作为目标目录；松在桌面时使用桌面目录，松在其他窗口时使用跨屏桥的默认接收目录。确认框会显示最终识别到的完整路径。

跨屏鼠标控制使用 UDP 45992。Windows 防火墙需要允许该端口的专用网络入站流量。
资源管理器选择会优先通过 Windows Shell 获取；如果系统未暴露 Shell 选择接口，软件会短暂模拟复制并读取文件列表，然后恢复原剪贴板内容。

如果自动发现没有显示设备，可在“手动连接”输入框中填写另一台电脑的 IPv4 地址。程序会先测试 TCP 45991，连接成功后设备会立即进入列表。

## 网络端口

- UDP 45990：局域网设备发现
- TCP 45991：文件传输

如果设备互相看不到，请确认两台电脑处于“专用网络”，并允许 PowerShell 通过防火墙。

## 当前版本说明

这是无需安装开发环境的 MVP。它已经支持逐网卡自动发现、手动 IP 连接、全局快捷键、拖放、完整文件夹结构、可配置接收目录、传输进度和自动重命名冲突文件。

单个文件上限为 100 GB。发送端必须收到接收端“已保存”的确认后才会显示发送成功；连接中断或协议版本不一致会明确显示失败。

真正把 Windows Explorer 的拖拽光标无缝接管到另一台物理电脑，需要实现 Windows Shell/OLE 拖放代理和跨设备鼠标边缘捕获；这部分适合在验证传输稳定后加入原生安装版。
